# GoGMGo Website — Master Prompt

## Project Goal
Build a high-converting, SEO-optimized, mobile-first marketing website for GoGMGo, an F&B SaaS platform for restaurants, cafes, and chains.

## Brand Positioning
GoGMGo is the modern restaurant operating system: POS, QR ordering, procurement, HR, inventory, reporting, payments, and integrations in one platform.

Primary concept:
"The POS That Installs Itself"

The website must feel:
- premium
- modern
- clear
- founder-led
- credible for restaurants and chains
- more like a serious SaaS company than a generic POS vendor

## Core Website Sections
Build the homepage with these sections:
1. Hero
2. Pain / current restaurant tech is broken
3. Prep section — keep the exact original strategic concept and wording from the approved prompt
4. Special Sauce section
5. Product ecosystem
6. Integrated payments
7. Reporting / analytics / AI insights
8. Implementation / onboarding
9. Testimonials or proof
10. CTA section
11. Footer

## Footer Requirements
Footer must include:
- GoGMGo logo
- Privacy Policy link
- Terms & Conditions link
- Contact details
- Copyright

Privacy Policy and Terms & Conditions must each have their own editable CMS page.

## Backend Admin Panel Requirements
Create a small admin panel where I can control:
- homepage text sections
- SEO title
- SEO meta description
- Open Graph image
- page slugs
- Privacy Policy page content
- Terms & Conditions page content
- HubSpot integration settings
- tracking scripts
- CTA destination links

The Privacy Policy and Terms pages should support mini word-doc style formatting:
- headings
- bold
- italic
- bullet lists
- numbered lists
- links
- spacing
- tables if practical

## SEO Requirements
Every public page must support:
- custom meta title
- custom meta description
- canonical URL
- Open Graph title
- Open Graph description
- Open Graph image
- structured schema where appropriate
- sitemap.xml
- robots.txt
- clean URLs
- fast page load

## Mobile Requirements
The site must be fully responsive:
- mobile-first
- strong CTA visibility
- no tiny text
- sections must stack elegantly
- admin panel should also be usable on laptop/tablet

## Suggested Tech Stack
Use:
- Next.js
- TypeScript
- Tailwind CSS
- Prisma
- PostgreSQL or SQLite for local development
- Rich text editor for CMS pages
- HubSpot forms or tracking integration

## Build Rules
Before coding, always:
1. inspect the existing file structure
2. propose a plan
3. ask before deleting major files
4. keep changes clean and modular
5. run lint/build checks after implementation

## Quality Bar
Do not create a generic template. The website should feel specific to GoGMGo and restaurant operators.
